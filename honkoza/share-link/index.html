作った資料を、
タップで開くリンクにする

Claudeに「リンクにして」と言うだけで、
お客さまにそのまま送れる形になります。

⏱ 準備は、はじめの1回だけ（30〜60分）

Claudeが止まるのには、理由があります

「リンクにして」と頼んでも、Claudeが止まってしまう。
その理由は、たいてい次の3つです。

☁

Claudeが「クラウド」で動いている

Macの外にある作業場なので、公開の手続きまで手が届きません。

🔒

置き場所が「非公開」になっている

無料のGitHubでは、非公開の置き場所からページを出せません。

🛡

お客さまの情報の守り方を、まだ伝えていない

だからClaudeは「出していいのかな」と迷って止まります。
これは正しい判断です。

この3つを、上から順にほどいていきます。
準備は最初の1回だけです。

始める前に、2つだけ

  • 🏢
    会社のルールを確かめます。
    会社や代理店に所属している方は、お客さまの資料を社外の場所に置いてよいかを、先に確かめてください。
    置けない決まりなら、この手順は使わずに会社のやり方で送ります。
  • 🐙
    GitHubのアカウント（無料）を用意します。
    まだない方は、ここで作れます。https://github.com/signup途中で、メールやスマホに届く確認コードを聞かれることがあります。

  4. フォルダを聞かれたら、1で作った share を選びます。

    雲のマーク☁がどこにも出ていなければOK

2Macの道具をそろえて、GitHubとつなぐ

15〜40分
  1. 1で開いた新しい画面に、下の文をそのまま貼って送ります。
貼る文 ①　道具をそろえてつなぐ
このMacで、GitHubに資料を公開できるように準備してください。
・git・node・gh（GitHubの道具）が入っているか確かめて、ないものを入れてください。
・Homebrew がないときは、Macのパスワードがいらない方法（それぞれ公式の配布ファイルを ~/.local に置く）で入れて、~/.local/bin を ~/.zshrc の PATH に足してください。
・Macの「デベロッパ・ツール」のインストール画面が出たら、私が「インストール」を押します。終わるまで待ってください。
・gh auth login --web --git-protocol https を裏で動かして、出てきた8けたのコードを先に大きく見せてください。私が https://github.com/login/device で許可します。
・つながったら gh auth setup-git も動かしてください。
・git の名前はGitHubの名前、メールはGitHubの noreply のアドレス（ID+名前@users.noreply.github.com）で設定してください。
・最後に、全部そろったかを教えてください。
  1. Claudeが「実行してよいですか」と何度か聞いてきます。
    この手順の中なら、何度出ても「許可」でOKです。
  2. Macの画面に「デベロッパ・ツールが必要です」と出たら、「インストール」を押します。
    Macのパスワードを聞かれたら、ご自身で入れます。
    終わるまで10分ほどかかることがあります。
    終わったら、Claudeに「インストールが終わりました」と送ります。
  3. 8けたのコード（例：ABCD-1234）が出たら、次のページを開きます。https://github.com/login/device
  4. コードを入れて「Continue」を押し、緑の「Authorize」ボタンを押します。
    GitHubのログインを聞かれたら、ご自身で入れてください。
  5. Claudeの画面に戻ります。
    「そろいました」と返ってくればOK

3置き場所と、鍵の仕組みを作る

5分

置き場所そのものは「公開」にします。
そのかわり、中身は鍵がないと読めない形で置きます。
鍵は資料ごとに別々なので、Aさんに送ったリンクで、Bさんの資料は開きません。
鍵と元の資料はMacの中にしまい、GitHubには上げない設定にします。

  1. 同じ画面に、下の文をそのまま貼って送ります。
貼る文 ②　置き場所と鍵を作る
渡す資料の置き場所を作ってください。順番どおりに進めてください。
1. いま開いているフォルダ（share）に、次のひな形を curl でそのまま保存してください。書き写したり、作り直したりはしないでください。
https://mm738966m-boop.github.io/ai-aibou-shindan/honkoza/share-link/build.mjs
2. node build.mjs を一度動かしてください。GitHubに上げない物の設定が、最初に作られます。
3. git init -b main をして、GitHubに公開リポジトリ「share」を作り、つないでください（同じ名前があれば share-2）。自分で git add や commit はしないでください。
4. もう一度 node build.mjs を動かしてください。GitHubへ送られます。
5. GitHub Pages を、main ブランチの /（root）で有効にしてください。
6. 公開先のURLを教えてください。
  1. 「公開リポジトリを作ってよいですか」と聞かれたら、「はい」と答えます。
  2. 最後にURLが出れば完了です。
    https://（GitHubの名前）.github.io/share/ の形ならOK
    share-2 など、最後の名前が少し違っていても大丈夫です。

4Claudeに、渡し方のルールを伝える

2分

このルールを一度伝えておくと、次からは「リンクにして」の一言で、毎回同じやり方で作ってくれます。

  1. 同じ画面に、下の文をそのまま貼って送ります。
貼る文 ③　渡し方のルール
次のルールを ~/.claude/CLAUDE.md に書き足して、これからずっと守ってください。

## 人に渡す資料はリンクにする
- 人に渡す資料は、デスクトップの share フォルダの src/ にHTMLで置き、share フォルダで node build.mjs を動かす。暗号化・記録・GitHubへの送信まで build.mjs がやるので、git add や commit は自分でしない。
- 資料を直すときは、src/ の同じファイル名のまま上書きする。名前を変えたり消したりしない（送ったリンクが開かなくなる）。
- build.mjs が 🚨 で止まったら、表示のとおりに対応し、--yes は私に確かめてから使う。
- PDFや文章で届いた資料は、スマホで読みやすいHTMLに作り直してから src/ に置く。画像はHTMLの中に埋め込む。share フォルダの直下と p/ には何も置かない。
- お渡し資料には、計測タグ（Metaピクセル・Googleアナリティクスなど）を入れない。
- 渡すリンクは、build.mjs が最後に出す「?k=」つきのURL。資料ごとに鍵が違う。省略せず、伏せ字にせず、全部見せる。
- シェアしたときの題名は <meta name="share-title" content="…"> に書く。ここは暗号化されないので、お名前・金額・病気は入れず、「お金の地図」のような資料の種類だけにする。src/ のファイル名は外に出ない。
- 暗号化しないまま公開しない。アーティファクトやメールの下書きで代わりにしない。
- 公開したら1〜2分待ち、?k= を外したURLを curl で開いて 200 になることを確かめてから報告する。はじめての公開は10分ほどかかることがあるので、200にならなくても10分までは待って何度か試す。設定の作り直しや送り直しはしない。
- 「この資料の公開をやめて」と言われたら、node build.mjs --stop ファイル名.html を動かす。

「書き足しました」と出ればOK

5ためしに1本、リンクにしてみる

5分
  1. 渡したい資料のファイルを、Finder（デスクトップやダウンロードのフォルダ）から、Claudeの入力欄へドラッグして入れます。
  2. 続けて、下の文を送ります。
貼る文 ④　リンクにする
この資料を、スマホで読みやすいページにして、リンクにしてください。
  1. 出てきたURLを、最後まで全部コピーします。
    URLの終わりに ?k= と英数字がついていれば、それが渡すリンクです。
  2. そのURLを、LINEの自分用のトーク（Keepメモ）に送って、スマホで開きます。
    資料の中身が出ればOK
  3. 鍵の確かめもしておきます。
    Macのブラウザのアドレス欄にURLを貼り、?k= から後ろを消して開きます。
    「お送りしたリンクから、もう一度開いてください」と出て、中身は見えません。

公開してから見られるようになるまで、1〜2分かかります。
はじめての1本は、10分ほどかかることがあります。

6お客さまに送る前に

1分
  1. 送る相手を、もう一度見ます。
    リンクを知っている人は、その資料を開けます。
    宛先とお名前を確かめてから送ります。
  2. 間違えて送ったときは、止められます。
    Claudeに「この資料の公開をやめて」と伝えます。
    数分で、リンクから開かなくなります。
